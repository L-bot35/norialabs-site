Política de Privacidad

Última actualización: 2 de octubre de 2026.

Esta política explica cómo NORIA LABS trata los datos personales relacionados con el sitio norialabs.site y con Presupuesto Rápido PRO. El responsable del tratamiento es NORIA LABS, operado desde Ecuador. Para consultas o ejercicio de derechos puedes escribir a soporte@norialabs.site.

1. Datos que podemos tratar

  • Cuenta y autenticación: correo electrónico, identificador de usuario, estado de la cuenta y datos necesarios para iniciar sesión y recuperar acceso.
  • Perfil del negocio: nombre comercial, teléfono, correo comercial, logo, idioma, moneda y preferencias de impuestos que el usuario decida configurar.
  • Cotizaciones: datos que el usuario ingrese para preparar presupuestos, como cliente, proyecto, ubicación, materiales, personal, gastos, condiciones y valores.
  • Licencia y pagos: identificadores de transacción, estado de pago o suscripción, fechas, importe, moneda y correo asociado a la compra. Los datos completos de tarjeta no son almacenados por NORIA LABS; el pago es procesado por Hotmart.
  • Dispositivos y seguridad: identificador aleatorio de instalación, nombre general del dispositivo/navegador, fechas de uso y registros técnicos necesarios para seguridad y control de acceso.

2. Para qué usamos los datos

  • Crear y administrar la cuenta del usuario.
  • Verificar la suscripción y autorizar los dispositivos permitidos.
  • Guardar, recuperar, duplicar y gestionar cotizaciones del usuario.
  • Generar cotizaciones para clientes e informes internos.
  • Procesar activaciones, renovaciones, cancelaciones, reembolsos y soporte.
  • Prevenir fraude, abuso, acceso no autorizado y proteger la seguridad del servicio.
  • Cumplir obligaciones legales, contractuales, contables o de atención de reclamaciones cuando correspondan.

3. Base del tratamiento

Tratamos los datos principalmente porque son necesarios para ejecutar la suscripción y prestar el servicio solicitado. También podemos tratar datos para cumplir obligaciones legales y para proteger la seguridad e integridad de la plataforma. Cuando una finalidad requiera consentimiento separado, este se solicitará de forma específica.

4. Proveedores y transferencias

Para operar el servicio utilizamos proveedores tecnológicos que pueden procesar datos en nuestro nombre, entre ellos Supabase (autenticación, base de datos y funciones), Cloudflare y/o GitHub Pages (infraestructura y publicación), y Hotmart (checkout, pagos y gestión de suscripciones). El uso de servicios globales puede implicar tratamiento o almacenamiento fuera de Ecuador. Cuando corresponda, NORIA LABS procurará que dichas transferencias se realicen con las salvaguardas exigibles por la normativa aplicable.

5. Conservación

Los datos de cuenta, perfil y cotizaciones se conservan mientras la cuenta esté activa y durante el tiempo razonablemente necesario para prestar soporte, atender reclamaciones o cumplir obligaciones aplicables. Los registros de transacciones y seguridad pueden conservarse por períodos adicionales cuando sean necesarios para obligaciones legales, contables, prevención de fraude o defensa de derechos. El usuario puede solicitar eliminación cuando legalmente proceda.

6. Derechos del titular

El usuario puede solicitar acceso, rectificación, actualización, eliminación, oposición, limitación y, cuando corresponda, portabilidad de sus datos. También puede solicitar una copia estructurada de los datos de su cuenta escribiendo a soporte@norialabs.site. La solicitud podrá requerir verificación de identidad para proteger la cuenta.

7. Datos incluidos por el usuario en sus cotizaciones

El usuario es responsable de contar con una base legítima para incluir datos personales de sus propios clientes o terceros en las cotizaciones. NORIA LABS procesa esa información únicamente para prestar las funciones de Presupuesto Rápido PRO y no la utiliza para contactar a esos terceros con fines comerciales propios.

8. Seguridad

Aplicamos controles de autenticación, licencias, límites de dispositivos y políticas de acceso a datos. Ningún sistema conectado a Internet puede garantizar seguridad absoluta; por ello mantenemos medidas razonables orientadas a reducir acceso, alteración o divulgación no autorizados.

9. Menores de edad

Presupuesto Rápido PRO está dirigido a personas que realizan actividades profesionales o comerciales y no está diseñado como servicio dirigido a menores.

10. Cambios a esta política

Podemos actualizar esta política cuando cambien el servicio, los proveedores o las obligaciones aplicables. La versión vigente se publicará en esta página con su fecha de actualización.

Contacto de privacidad: soporte@norialabs.site. Los titulares también pueden acudir a la autoridad competente de protección de datos conforme a la normativa ecuatoriana.
